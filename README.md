# dasi-check-project
가족 사칭 전화와 스미싱 문자 상황을 체험하고, 대화 연습·문자 퀴즈·URL 확인·공식 통계 학습으로 대응 역량을 기르는 Streamlit 웹앱
# 보이스피싱 예방 체험

신종 보이스피싱·스미싱 대응 역량을 기르는 체험형 예방 플랫폼

## 1. 프로젝트 소개

가족의 이름과 번호로 표시되는 의심 전화부터 후속 문자와 링크까지,
다양한 상황에서 상대를 확인하고 대응하는 방법을 연습하는
Streamlit 웹앱을 제작한다.

## 2. 주제 선정 배경

가족이나 지인의 번호로 표시되고 목소리도 비슷하게 들려
피해를 입었다는 영상 속 경험담을 접했다.

이를 계기로 익숙한 번호나 목소리만으로 상대를 믿기보다,
별도로 확인하는 과정을 연습할 필요가 있다고 생각했다.

## 3. 해결하려는 문제

상대가 가족이라고 주장하거나 긴급한 상황을 이야기하면
사용자가 확인 없이 요구에 따를 수 있다.

사용자가 상대를 믿게 된 단서와 실제 확인한 사실을 구분하고,
확인·거절·도움 요청 등의 대응을 연습하도록 돕고자 한다.

## 4. 대상 사용자

- 가족 사칭 전화 대응을 배우려는 학생과 보호자
- 의심 문자와 링크를 확인하는 방법을 배우려는 일반 사용자

## 5. 기존 방식과의 차별점

- 예방 안내를 읽는 데서 나아가 전화와 후속 문자가 연결된 상황을 체험한다.
- 정답·오답뿐 아니라 사용자의 대응 행동과 판단 이유를 함께 설명한다.
- 체험에서 부족했던 부분을 대화 연습, 문자 퀴즈, URL 확인으로 연결한다.

## 6. 제작할 페이지

| 페이지 | 구현할 기능 |
|---|---|
| 신종 보이스피싱 모의 체험 | 가상 수신 화면, 전화·후속 문자 대응 선택, 종료 후 리포트 |
| 모의 피싱 대화 연습 | 힌트와 응답별 설명을 받으며 대화 연습 |
| 문자 체험 퀴즈 | 가상 문자 3문항, 채점, 해설, 재도전 |
| 의심 URL 확인 도우미 | URL 입력창, 주소 형식 검사, 실제 호스트명과 의심 특징 설명 |
| 개념·최신 공식 통계 | 개념 설명, 공식 통계 그래프, 출처와 집계 기간 표시 |

## 7. 구현 기준

- 체험 점수는 사용자의 행동 기록이며 실제 피싱 확률이 아니다.
- 실제 AI 연결 전에는 대본 기반 체험이라고 표시한다.
- 가상 전화·문자·링크는 교육용 사례임을 명시한다.
- URL에서 의심 특징을 찾지 못해도 안전하다고 확정하지 않는다.
- 초기 URL 분석은 링크에 직접 접속하지 않고 주소 문자열을 분석한다.
- 통계에는 출처, 집계 기간, 발표일, 자료 확인일을 표시한다.

## 8. 개발 순서

1. 프로젝트 기획과 README 작성
2. 5개 페이지와 메뉴 이동 구조 구현
3. 문자 퀴즈 구현
4. 모의 전화와 후속 문자 체험 구현
5. 대응 리포트 구현
6. 대화 연습 구현
7. URL 확인 기능 구현
8. 개념·공식 통계 페이지 구현
9. 테스트와 오류 수정
10. Streamlit 배포 및 시연 준비

## 9. 현재 개발 상태

기획 단계이다. 이 저장소에는 아직 실행 가능한 앱을 구현하지 않았다.
기능을 완성할 때마다 실제 구현 상태에 맞춰 수정한다.

## 10. 사용법과 실행 방법

앱 구현 후 실제 실행 방법과 페이지별 사용법을 작성할 예정이다.

## 11. AI 활용 기록

기획 정리와 코드 학습에 AI의 도움을 받는다.
AI 답변의 실행 결과, 직접 수정한 내용과 이유를 실제 활동에 따라 기록한다.
