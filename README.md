# 잠깐! — 직접 해 보며 멈추는 연습을 하는 피싱 예방 체험 웹앱

> 가상의 도시 **도토리시**를 돌아다니며, 피싱 연락을 받은 순간 **멈추고, 확인하고, 판단하는** 연습을 하는 Streamlit 웹앱입니다.

- 🔗 배포된 앱: https://dasi-check-project-hl8ytrxmx6itu9c5oy9y24.streamlit.app/
- 2학기 고등학교 2학년 프로그래밍 · AI 활용 프로젝트

<br>

## 1. 프로젝트 소개

### 왜 만들었나요?
유튜버가 해외여행 중 겪은 보이스피싱 피해 영상을 보고 이 프로젝트를 시작했습니다. 범인은 발신번호를 속여 가족의 실제 번호가 화면에 뜨게 하고, AI로 복제한 목소리까지 들려주었습니다. 번호와 목소리가 그대로라서 가족은 확인할 틈 없이 돈을 보냈습니다.

학교에서는 예방 수칙을 글이나 영상으로만 배웁니다. 그래서 수법을 **알고 있어도**, 실제 연락을 받은 순간에 **멈추고 확인하는 행동**으로 이어지지 않습니다. '잠깐!'은 이 차이를 메우기 위해, 사용자가 직접 상황 속에 들어가 판단하고 결과를 확인하는 연습을 하도록 만들었습니다.

### 누구를 위한 앱인가요?
- **주 대상**: 휴대폰으로 단톡방, SNS, 중고거래 앱을 매일 쓰는 고등학생
- **함께 쓰는 사람**: 부모님·조부모님 등 가족 (큰 글씨 모드 제공)
- **실제 피해가 의심되는 누구나**: '피해가 의심될 때' 페이지에서 바로 할 일 확인

### 기존 방식과 무엇이 다른가요?
| 기존 예방 자료 | 잠깐! |
|---|---|
| 사기범 녹음을 **듣기만** 한다 | 내 선택에 따라 **결말이 달라지는** 게임으로 체험한다 |
| O/X 퀴즈로 **정답을 고른다** | 증거와 대화를 **비교해 스스로 판단**한다 |
| "알려 주지 마세요"라고 **안내만** 한다 | 사칭범 역할 **AI와 직접 대화**하며 거절을 연습한다 |
| 수법의 **이름을 소개**한다 | 조건(AND·OR), 암호, QR 원리 등 **정보 과목 원리로 이해**한다 |
| 모두에게 **같은 내용**을 보여 준다 | 다른 사람들의 **결과와 비교**해 많이 속는 지점을 확인한다 |

모든 기능은 도토리시의 장소로 배치되어 있습니다. 홈 화면의 **도토리시 지도**나 왼쪽 **사이드바 메뉴**에서 고르면 됩니다.

| 기능 (도토리시 장소) | 설명 |

| 📊 개념과 통계 (시립도서관) | 체험에서 만난 수법의 뜻과 경찰청 공식 통계를 출처와 함께 제공 |
| 📈 도토리시 통계청 (통계청) | 게임 결과를 이름 없이 숫자로 모아 결말 비율, 많이 틀린 문자 등을 그래프로 보여 주고 명예의 전당 TOP 20 공개 |

### 🪪 함께 쓰는 기능
- **도토리시 시민증**: 닉네임 하나로 만드는 시민증. 게임별 최고 기록이 명예의 전당에 올라갑니다. (이름·학번·이메일·비밀번호를 받지 않음)
- **시민증 도장판**: 활동을 끝낸 장소마다 도장이 찍혀 13곳을 모두 모으면 '명예 시민'이 됩니다. (저장하지 않고 이번 방문에만 유지)
- **다른 친구들은?**: 게임이 끝나면 같은 결과를 본 사람의 비율을 바로 보여 줍니다.
- **🔠 큰 글씨로 보기**: 사이드바 스위치로 화면 전체의 글씨와 버튼을 크게 키웁니다.

## 3. 사용법

1. **앱 접속**: 배포 주소로 들어가면 홈 화면과 도토리시 지도가 나옵니다.
2. **장소 고르기**: 지도에서 장소를 누르거나 사이드바 메뉴에서 기능을 고릅니다. 처음이라면 홈의 **'할머니 폰 지키기 시작하기'** 를 추천합니다.
3. **체험하기**: 각 페이지 위쪽의 '이용 순서'와 예시를 보고 시작 버튼을 누릅니다.
   - 예) 피싱 필터 만들기: 예시 보기 → '🤖 필터실 입장하기' → 조건 블록 조립 → '▶ 필터 실행' → 결과표 확인
4. **결과 확인**: 게임이 끝나면 결말, 해설, '다른 친구들은?' 비교가 나옵니다.
5. **기록 남기기 (선택)**: 메뉴 맨 위 **'도토리시 시민증'** 에서 닉네임으로 시민증을 만들면 최고 기록이 명예의 전당에 저장됩니다. 로그인하지 않아도 모든 게임을 할 수 있습니다.
6. **모두의 기록 보기**: **'도토리시 통계청'** 에서 사람들이 어디서 많이 속는지 그래프로 확인합니다.
7. **실제 피해가 의심될 때**: 메뉴 맨 위 **'피해가 의심될 때'** 에서 상황을 고르고 안내에 따라 112·118·금융회사에 먼저 연락합니다.

> ⚠️ 이 앱의 전화·문자·링크는 모두 교육용 가상 사례입니다. 실제 개인정보나 인증번호를 입력하지 마세요.

## 4. 실행 방법

### 배포된 앱으로 실행
위의 배포 주소로 접속하면 바로 사용할 수 있습니다.

### 내 컴퓨터에서 실행
1. Python 3.10 이상을 설치합니다.
2. 저장소를 내려받고 폴더로 이동합니다.
   ```bash
   git clone https://github.com/joowonlee1/dasi-check-project.git
   cd dasi-check-project
   ```
3. 필요한 라이브러리를 설치합니다.
   ```bash
   pip install -r requirements.txt
   ```
4. (선택) AI 대화와 통계 저장을 쓰려면 `.streamlit/secrets.toml` 파일을 만들고 **본인의 키**를 넣습니다. 이 파일은 GitHub에 올리지 않습니다.
   ```toml
   GEMINI_API_KEY = "여기에_본인의_Gemini_API_키"

   [firebase]
   api_key = "여기에_본인의_Firebase_웹_API_키"
   project_id = "여기에_본인의_Firebase_프로젝트_ID"
   ```
   - 키가 없어도 앱은 실행됩니다. AI 모의대화는 **오프라인 대본 모드**로 연습할 수 있고, 통계·명예의 전당은 저장되지 않습니다.
5. 앱을 실행합니다.
   ```bash
   streamlit run app.py
   ```
6. 브라우저에서 `http://localhost:8501` 이 열립니다.

### Streamlit Community Cloud에 배포할 때
- 저장소를 연결하고 Main file을 `app.py`로 지정합니다.
- 앱 설정의 **Secrets**에 위 4번과 같은 내용을 넣습니다. (키를 코드나 GitHub에 쓰지 않음)

## 6. 개인정보와 안전

- 이름·학번·학교·이메일·비밀번호를 받지 않습니다. 시민증은 **닉네임만** 사용합니다.
- 통계는 '몇 번 나왔는지' **숫자만 +1** 합니다. 누가 어떤 답을 했는지는 저장하지 않습니다.
- 데이터베이스 보안 규칙으로 통계는 늘리기만 할 수 있고, 다른 사람의 명예의 전당 기록은 고칠 수 없습니다.
- 의심 URL 확인은 입력한 주소에 **접속하지 않고** 문자열만 분석합니다. '특징 없음'이 '안전함'을 뜻하지는 않습니다.
- API 키는 코드와 GitHub에 쓰지 않고 Streamlit Secrets에만 저장합니다.
- 게임 속 점수와 유형은 학습용이며 실제 피해 확률이나 능력을 나타내지 않습니다.
