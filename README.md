> 가상의 도시 **도토리시**를 돌아다니며, 피싱 연락을 받은 순간 **멈추고, 확인하고, 판단하는** 연습을 하는 Streamlit 웹앱입니다.

- 🔗 배포된 앱: https://dasi-check-project-hl8ytrxmx6itu9c5oy9y24.streamlit.app/

## 1. 프로젝트 소개

### 왜 만들었나요?
요즘 피싱 범인은 발신번호를 속여 가족의 실제 번호가 화면에 뜨게 하고, AI로 복제한 목소리까지 들려주기도 합니다. 번호와 목소리가 그대로라면 누구라도 확인할 틈 없이 돈을 보낼 수 있습니다.

학교에서는 예방 수칙을 글이나 영상으로만 배웁니다. 그래서 수법을 **알고 있어도**, 실제 연락을 받은 순간에 **멈추고 확인하는 행동**으로 이어지지 않습니다. '잠깐!'은 이 차이를 메우기 위해, 사용자가 직접 상황 속에 들어가 판단하고 결과를 확인하는 연습을 하도록 만들었습니다.

### 누구를 위한 앱인가요?
- **주 대상**: 휴대폰으로 단톡방, SNS, 중고거래 앱을 매일 쓰는 고등학생
- **함께 쓰는 사람**: 부모님·조부모님 등 가족 (큰 글씨 모드 제공)
- **실제 피해가 의심되는 누구나**: '피해가 의심될 때' 페이지에서 바로 할 일 확인

### 기존 방식과 무엇이 다른가요?
| 기존 예방 자료 | 잠깐! |
|---|---|
| 사기범 녹음을 **듣기만** 한다 | 내 선택에 따라 **결말이 달라지는** 게임으로 체험한다 |
| O/X 퀴즈로 **정답을 고른다** | 증거와 대화를 **비교해 스스로 판단**한다 |
| "알려 주지 마세요"라고 **안내만** 한다 | 사칭범 역할 **AI와 직접 대화**하며 거절을 연습한다 |
| 수법의 **이름을 소개**한다 | 조건(AND·OR), 압축(RLE), 제약 조건, 등록 도메인 같은 **정보 과목 원리로 이해**한다 |
| 모두에게 **같은 내용**을 보여 준다 | 다른 사람들의 **결과와 비교**해 많이 속는 지점을 확인한다 |

## 2. 주요 기능

모든 기능은 도토리시의 장소 14곳에 배치되어 있습니다. 홈 화면의 **도토리시 그림 지도**나 왼쪽 **사이드바 메뉴**에서 고르면 됩니다.

### 🚑 피해 도움
| 기능 (도토리시 장소) | 설명 |
|---|---|
| 🚨 피해가 의심될 때 (시민안전센터) | '돈을 보냈어요', '앱을 설치했어요' 등 11가지 상황을 고르면 지금 할 일과 112·118·금융회사 연락처를 공식 출처와 함께 안내하고, '지금 할 일 카드'를 사진으로 저장 |

### 🎮 체험과 연습
| 기능 (도토리시 장소) | 다루는 수법 | 설명 |
|---|---|---|
| 📱 할머니 폰 지키기 (할머니 댁) | 가족·기관 사칭 | 진짜 연락 3개와 사기 연락 4개가 오는 동안 언제, 어떻게 끼어들지 고르거나 **직접 말해서** 설득(AI가 0~2점 채점)하고 4가지 결말 중 하나를 확인 |
| 💬 AI 모의대화 (대화 연습실) | 7가지 사칭 | 사칭범 역할의 AI(Gemini)에게 **글이나 말(음성)**로 답하며 거절·확인을 연습하고 대응 리포트를 받음. AI가 안 되면 오프라인 대본 모드 |
| 🗝️ 피싱 방탈출 (민서네 집) | 발신번호 조작 | 같은 엄마 번호로 온 서로 다른 연락의 증거를 '나의 폰'(문자·전화)으로 비교해 30분 안에 3단계 잠금을 풀고 탈출 |
| 🌐 가짜뉴스 확산 막기 (도토리 광장) | 가짜 소식 확산 | 이웃 연결망에서 누구를 먼저 지키고 누구에게 근거 있는 정정 문구를 보낼지 고르는 5단계 전략 게임 + 같은 사진을 다르게 잘라 보는 **사진 비교 체험** |
| 🕵️ 단톡방 마피아 (2학년 3반 단톡방) | 친구 계정 도용 | 대화를 읽고 친구 5명 중 사칭범을 조사 3번으로 찾는 추리 게임 (1~4명, 휴대폰을 돌려 가며 가능) |
| 🔐 중고거래 사기단 추리 (중고마켓) | 중고거래 사기 | 거래 기록 3건을 조사해 결론과 근거로 단서를 얻고, 추리 표를 채워 판매자 5명 중 진짜 1명을 찾는 추리 퍼즐 (막히면 AI 탐정에게 질문) |
| 🤖 피싱 필터 만들기 (우체국 필터실) | 스미싱 문자 | AND·OR 조건 블록으로 가짜 문자만 거르는 필터를 만들고 오탐·미탐을 줄인 뒤, 처음 보는 **새 문자 시험**으로 검증 |
| 🧩 큐싱 노노그램 (공영주차장) | QR 코드 사기 | 숫자 단서로 칸을 칠해 찢긴 QR 스티커를 복원하고, 단계마다 그 QR을 써도 되는지 근거 자료를 조사 |
| 📬 가짜 안내서 감별소 (아파트 관리사무소) | 우편물 안내서 사칭 | 문 3개에 붙은 등기 우편물 안내서를 안내서 속 QR·번호가 아닌 **직접 찾은 공식 경로**로 확인해 정상·위조·판단 보류를 근거와 함께 판정 |
| 🧭 대처유형 테스트 (시민 등록소) | 나의 대처 습관 | 12문항에 답하면 16가지 교육용 유형 중 나의 유형과 조심할 점을 알려 주고, 서약의 벽에 참여 |

### 📚 확인과 학습
| 기능 (도토리시 장소) | 설명 |
|---|---|

| 📊 개념과 통계 (시립도서관) | 체험에서 만난 수법 16가지의 뜻과 경찰청 공식 통계를 출처와 함께 제공 |
| 📈 도토리시 통계청 (통계청) | 게임 결과를 이름 없이 숫자로 모아 결말 비율, 많이 틀린 문자 등을 그래프로 보여 주고 명예의 전당 TOP 20 공개 |

### 🪪 함께 쓰는 기능
- **깡지 소개 화면**: 처음 들어오면 '로그인 없이 둘러보기 / 새 시민증 만들기 / 다시 들어오기' 중 하나를 고릅니다.
- **깡지 도우미**: 모든 화면 오른쪽 아래의 깡지를 누르면 그 화면의 사용법을 보여 주고, 궁금한 점을 AI에게 질문할 수 있습니다. 게임의 정답은 알려 주지 않습니다.
- **도토리시 시민증**: 닉네임과 인증용 비밀 숫자 6자리로 만드는 시민증. 게임별 최고 기록이 명예의 전당에 올라갑니다. (이름·학번·실제 이메일은 입력받지 않음)
- **시민증 도장판·업적 배지**: 장소 14곳의 활동을 마치면 도장이 찍히고, 도전 과제를 달성하면 업적 배지(10종)를 받습니다. 시민증으로 로그인하면 계정에 저장되고, 비회원은 이번 방문에만 유지됩니다.
- **다른 친구들은?**: 게임이 끝나면 같은 결과를 본 사람의 비율을 바로 보여 줍니다.
- **🔠 큰 글씨로 보기 · 🔊 효과음**: 사이드바에서 화면 전체 글씨를 키우고, 효과음을 켜고 끄거나 음량을 조절합니다.
- **관리실**: 관리자 코드로 들어가 비밀 숫자 재설정, 시민·기록 정리, 게임 정답 확인을 합니다.

## 3. 사용법

1. **앱 접속**: 배포 주소로 들어가면 깡지 소개 화면이 나옵니다. **로그인 없이 둘러보기**를 누르거나 시민증을 만들거나(다시 들어오기) 하면 도토리시 지도를 볼 수 있습니다. 실제 피해가 의심되면 맨 위 **'실제 피해가 의심되나요?'** 버튼으로 바로 갑니다.
2. **장소 고르기**: 지도에서 장소를 누르거나 사이드바 메뉴에서 기능을 고릅니다. 홈의 **깡지 추천 버튼**은 받은 도장을 보고 다음 장소를 추천합니다. 처음이라면 '할머니 폰 지키기'를 추천합니다.
3. **체험하기**: 각 페이지 위쪽의 '이용 순서'와 예시를 보고 시작 버튼을 누릅니다. 막히면 오른쪽 아래 깡지 도우미에게 물어봅니다.
   - 예) 피싱 필터 만들기: 예시 보기 → '🤖 필터실 입장하기' → 조건 블록 조립 → '▶ 필터 실행' → 결과표 확인 → 새 문자 시험
4. **결과 확인**: 게임이 끝나면 결말, 해설, '다른 친구들은?' 비교가 나옵니다.
5. **기록 남기기 (선택)**: 메뉴 맨 위 **'도토리시 시민증'** 에서 닉네임과 인증용 비밀 숫자 6자리로 시민증을 만들면 도장·배지와 최고 기록이 저장됩니다. 로그인하지 않아도 모든 게임을 할 수 있습니다.
6. **모두의 기록 보기**: **'도토리시 통계청'** 에서 사람들이 어디서 많이 속는지 그래프와 명예의 전당으로 확인합니다.
7. **실제 피해가 의심될 때**: 메뉴의 **'피해가 의심될 때'** 에서 상황을 고르고 안내에 따라 112·118·금융회사에 먼저 연락합니다.

> ⚠️ 이 앱의 전화·문자·링크는 모두 교육용 가상 사례입니다. 실제 개인정보나 인증번호를 입력하지 마세요.

## 4. 실행 방법

### 배포된 앱으로 실행
위의 배포 주소로 접속하면 바로 사용할 수 있습니다.

### 내 컴퓨터에서 실행
1. Python 3.10 이상을 설치합니다.
2. 저장소를 내려받고 폴더로 이동합니다.
   ```bash
   git clone https://github.com/joowonlee1/dasi-check-project.git
   cd dasi-check-project
   ```
3. 필요한 라이브러리를 설치합니다.
   ```bash
   pip install -r requirements.txt
   ```
4. (선택) AI 기능과 기록 저장을 쓰려면 `.streamlit/secrets.toml` 파일을 만들고 **본인의 키**를 넣습니다. 이 파일은 GitHub에 올리지 않습니다.
   ```toml
   # AI 기능(모의대화·할머니 폰 채점·깡지 도우미·AI 탐정·사진 평가)
   GEMINI_API_KEY = "여기에_본인의_Gemini_API_키"
   # HELPER_MODEL = "gemini-3.5-flash-lite"        # (선택) 깡지 도우미 모델
   # PHOTO_REVIEW_MODEL = "gemini-3.5-flash-lite"  # (선택) 사진 평가 모델

   # 시민증·통계·명예의 전당·서약의 벽
   [firebase]
   api_key = "여기에_본인의_Firebase_웹_API_키"
   project_id = "여기에_본인의_Firebase_프로젝트_ID"

   # (선택) 관리실: 관리자 코드
   [admin]
   code = "여기에_관리자_코드"

   # (선택) 관리실의 비밀 숫자 재설정·계정 삭제에 쓰는 Firebase 서비스 계정 키(JSON의 항목들)
   [firebase_admin]
   # type = "service_account"
   # project_id = "..."
   # private_key = "..."
   # client_email = "..."

   # (선택) 서버가 다시 시작돼도 새로고침 로그인 유지를 이어 가기 위한 32자 이상의 임의 문자열
   [login_persistence]
   key = "여기에_32자_이상의_임의_문자열"
   ```
   - 키가 없어도 앱은 실행됩니다. AI 모의대화는 **오프라인 대본 모드**로 연습할 수 있고, 시민증·통계·명예의 전당은 저장되지 않습니다.
5. 앱을 실행합니다.
   ```bash
   streamlit run app.py
   ```
6. 브라우저에서 `http://localhost:8501` 이 열립니다.

### Streamlit Community Cloud에 배포할 때
- 저장소를 연결하고 Main file을 `app.py`로 지정합니다.
- 앱 설정의 **Secrets**에 위 4번과 같은 내용을 넣습니다. (키를 코드나 GitHub에 쓰지 않음)

## 5. 사용 기술

| 구분 | 내용 |
|---|---|
| 언어·프레임워크 | Python, Streamlit 1.66.1 (멀티 페이지 `st.navigation`) |
| AI | Google Gen AI SDK (Gemini, 기본 모델 `gemini-3.5-flash-lite`) — AI 모의대화의 사칭범 역할과 대응 리포트, 음성 답변 받아쓰기, 할머니 폰 '직접 말하기' 채점, 깡지 도우미, 중고거래 AI 탐정, 사진 비교 체험 피드백 |
| 데이터베이스 | Firebase Authentication(비회원 익명 인증·시민증 로그인) + Cloud Firestore REST API — 익명 통계(+1 집계), 시민증(도장·배지), 명예의 전당, 서약의 벽 |
| 게임 화면 | HTML·CSS·JavaScript로 만든 Streamlit 사용자 정의 컴포넌트 (가짜뉴스, 사기단 추리, 피싱 필터, 노노그램) |
| 소리 | 브라우저 Web Audio(효과음)와 Web Speech(통화 목소리) — 소리 파일 없이 브라우저에서 만듦 |
| 기타 | `tldextract`·`idna`(주소의 등록 도메인 계산), `cryptography`(로그인 유지 토큰 암호화), pandas·Streamlit 차트 |

## 6. 개인정보와 안전

- 이름·학번·학교·실제 이메일은 입력받지 않습니다. 시민증은 **닉네임과 인증용 비밀 숫자 6자리**를 사용하며 Firebase Authentication으로 인증합니다. 비밀 숫자는 이 앱이 저장하지 않고 Firebase가 암호화해 보관합니다. 다른 서비스의 비밀번호나 생일은 사용하지 마세요.
- 통계는 '몇 번 나왔는지' **숫자만 +1** 합니다. 누가 어떤 답을 했는지는 저장하지 않습니다. 반복 참여가 포함될 수 있는 활동 횟수이며, 고유 참여자 수나 실제 피해 확률·학습 효과를 뜻하지 않습니다.
- 데이터베이스 보안 규칙으로 통계는 늘리기만 할 수 있고, 다른 사람의 명예의 전당 기록은 고칠 수 없습니다.
- 의심 URL 확인은 입력한 주소에 **접속하지 않고** 문자열만 분석합니다. '특징 없음'이 '안전함'을 뜻하지는 않습니다.
- AI 모의대화와 깡지 도우미는 전화번호·인증번호처럼 보이는 입력을 AI로 보내지 않고 걸러 냅니다.
- API 키는 코드와 GitHub에 쓰지 않고 Streamlit Secrets에만 저장합니다.
- 게임 속 점수와 유형은 학습용이며 실제 피해 확률이나 능력을 나타내지 않습니다.

### 사진 비교 체험의 AI 평가
- 사진 촬영·자르기는 브라우저에서 진행합니다. **AI 전송 동의 후 평가 버튼을 누른 경우에만** 원본·수정 전후 사진과 제목·설명이 앱 서버를 거쳐 Google Gemini로 전송됩니다.
- 앱은 이 사진을 파일·DB·로그에 저장하지 않습니다. 외부 AI 서비스의 처리 정책은 별도로 적용됩니다. 실제 개인정보가 담긴 사진 대신 예시 그림을 사용할 수 있습니다.
- `GEMINI_API_KEY`를 사용하며, 필요하면 Secrets의 `PHOTO_REVIEW_MODEL`로 이미지 입력과 JSON 응답을 지원하는 모델을 지정합니다. 기본값은 `gemini-3.5-flash-lite`입니다.
- AI 평가는 사진과 설명의 타당성에 대한 학습 피드백이며 실제 사건의 진위 인증이 아닙니다. 연결 실패·불확실한 평가는 통과로 처리하지 않습니다.

### 새로고침과 로그인 유지
- 같은 브라우저 탭에서 새로고침하면 소개 화면보다 먼저 저장된 암호화 토큰을 읽고 Firebase 계정을 다시 확인합니다. 비밀 숫자는 브라우저에 저장하지 않습니다.
- 유지 시간은 시민증 24시간, 관리자 8시간입니다. 직접 로그아웃하거나 시간이 지나면 다시 로그인합니다.
- 서버 재시작·재배포 후에도 유지하려면 Secrets에 `[login_persistence] key`(32자 이상) 또는 `[firebase_admin] private_key`가 있어야 합니다. 둘 다 없으면 앱이 켜져 있는 동안에만 쓰는 임시 키를 사용합니다. 임시 키와 계정 토큰은 코드에 기록하지 않습니다.
